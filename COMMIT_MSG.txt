v0.0.34: 新增 5 家实时语音适配 + admin 模型说明手册

- llm.rs 新增/增强 provider：
  * openai-realtime: Azure 支持（自动改发 api-key 头；地址自带查询串时不再追加 ?model=）；
    新增 GA 听录会话（gpt-live-transcribe / gpt-realtime-whisper -> session.type=transcription +
    嵌套 audio.input.*）；修复 OpenAI 家族输入采样率（16k->24k 上采样，原来会被按 24k 解释、语速x1.5）
  * gemini-live: Google Gemini Live（setup / realtimeInput / serverContent；翻译型模型取译文通道）
  * deepgram: nova-3 流式转写（Token 鉴权，中间结果前缀差分，is_final/UtteranceEnd 断句）
  * assemblyai: Streaming v3（裸 key，按 turn 出字幕）
  * volc-asr: 火山引擎豆包双向流式识别（官方二进制协议：4 字节头 + 大端长度 + gzip 首包；
    X-Api-Key/X-Api-Resource-Id 鉴权；utterances.definite 断句）；Model 字段填资源 ID
  * xfyun-rtasr: 讯飞实时语音转写（signa = Base64(HmacSHA1(MD5(appid+ts), apiKey))；
    40ms/1280B 二进制分帧；word 数组拼句）
- Cargo: 新增 flate2 / hmac / sha1 / md-5（均为纯 Rust，不影响三平台交叉编译）
- admin: 「1. 大模型」里的提示框移入「模型适配说明」弹窗以节省版面；
  弹窗新增「30 秒选择指南」+ 12 家服务逐一说明（Key 怎么填 / Model 怎么填 / Base URL /
  推荐场景 / 注意事项），并自动高亮并滚动到当前正在使用的服务
