2. 音频输入

系统音频环回 = 抓取 OBS 当前听到的声音；麦克风 = 抓指定输入设备。

🔒 引擎由 OBS 插件启动，音频由插件直接送入，模式已锁定。

3. OBS 集成

插件自动连接本机 OBS（obs-websocket v5），可把字幕同步写入一个"Subtitles"文本源。

想把控制台钉到 OBS 侧边栏？OBS → 顶部菜单 工具 → 自定义浏览器停靠面板 (Custom Browser Docks) → 填入 ，名称随意。

4. 字幕样式

这些值会写入浏览器源的 URL hash 覆盖默认值。字幕强制显示为一行。
